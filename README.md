## 🎯 Спецификация аудио

- **Формат:** WAV PCM 16-bit
- **Частота дискретизации:** 22050 Hz
- **Каналы:** моно
- **Нормализация громкости:** loudnorm I=-23 LUFS, TP=-3 dB, LRA=7

## 🔧 Как было сделано

1. **Поиск** видео через `z-ai web_search` (запросы «Сергей Бурунов интервью rutube», «vk видео»)
2. **Скачивание** через `yt-dlp` (YouTube заблокировал IP, использовали VK Видео)
3. **Извлечение аудио**: `ffmpeg -ar 22050 -ac 1` (моно, 22050 Hz)
4. **Нарезка по паузам**: `ffmpeg silencedetect` (порог -30dB, мин тишина 0.4 сек)
5. **Разбиение длинных сегментов**: равномерно по ~10 сек
6. **Нормализация**: `ffmpeg loudnorm I=-23:TP=-3:LRA=7`
7. **Сохранение**: WAV PCM 16-bit

## ⚠️ Ограничения качества

- **Без speaker diarization** — в интервью говорят двое (Бурунов + ведущий). Идеально было бы прогнать через `pyannote-audio` и оставить только сегменты Бурунова.
- **Без шумоочистки** — фоновый шум/эхо/заставки присутствуют. Можно докрутить `deepfilternet`.
- **Без текстовой расшифровки** — для TTS с alignment нужно прогнать через Whisper.

## 🎯 Рекомендации по улучшению

1. **Speaker diarization** — оставить только речь Бурунова:
   ```bash
   pip install pyannote.audio
   ```
2. **DeepFilterNet** — удалить фоновый шум
3. **Whisper large-v3** — расшифровать текст для alignment
4. **Ручная проверка** 20-30 случайных сегментов в Audacity
